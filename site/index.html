What shipped

The product spine you can clone and run — extractors, token graph, exporters, and the gates around them.

Extract → graph → export. Colors, spacing, typography, and shadows (plus shape and opacity) land in a token graph and leave as W3C JSON, CSS, a React theme, or Tailwind config.

W3C Design Tokens as the interchange. Compat+ coverage of the official $type set, with deltas called out in the conformance doc — not a private dump format.

Full stack with checks. FastAPI and React/TypeScript, local make check, Vitest, Playwright MVP smoke, and a GitHub Actions workflow. Look at the latest run rather than a frozen badge.

How I work with agents on this

Decisions and plans live in the repo first. Agents help draft and implement. I re-check against what’s actually on disk before anything counts as done.

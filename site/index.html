What shipped

The product spine you can clone and run — extractors, token graph, exporters, and the gates around them.

Extract → graph → export. Colors, spacing, typography, and shadows (plus shape and opacity) land in a token graph and leave as W3C JSON, CSS, a React theme, Tailwind config, or a Design Guide Pack.

W3C Design Tokens as the interchange. Compat+ coverage of the official $type set, with deltas called out in the conformance doc — not a private dump format.

Full stack with checks. FastAPI and React/TypeScript, local make verify, full Vitest and Python tests, mocked Playwright MVP checks, and GitHub Actions. Look at the latest run rather than a frozen badge.

How I work with agents on this

Decisions and plans live in the repo first. Agents help draft and implement. I re-check against what’s actually on disk before anything counts as done.

Claude and CV/OCR are in the extract path as tools. The roadmap, parked scope, and merge gate stay human.

Examples and verification

Illustrative export snippets and executable test links. Mocked browser tests verify UI behavior; they do not establish live extraction accuracy.

Product scope

The upload path stays focused on tokens and export. Mood and Lighting are opt-in tabs; geometry runs only on demand.

Ships

Opt-in and deferred

# Design Tokens Community Group Specs (Local Copies)

Offline references for W3C Design Tokens CG specs used by Copy That.

## Contents

- **`2025.10/`** — static mirror of the 2025.10 spec pages (format, color, resolver). Prefer this for offline reading.

Upstream (browser): [Design Tokens Community Group](https://github.com/design-tokens/community-group) and published TR pages.

## Update guidance

Refresh the static mirror with the same wget/mirror command used when the folder was created (see implementation notes in archive if needed). Do **not** expect a `community-group` git submodule in this repo — that path was removed.

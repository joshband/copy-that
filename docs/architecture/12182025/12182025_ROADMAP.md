## Sequenced Workstreams

### 1) Architecture & Boundary Hardening (ROADMAP_05)
Goal: keep domain/application/infrastructure separation intact and observable.
- Finish extractor wiring cleanup (no dead registrations, consistent orchestrators).
- Enforce port-only use-cases; block persistence/HTTP imports in `domain/`.
- Composition-only wiring; audit interfaces/routers to ensure they call application ports.
- Add lint/mypy rules or checks to prevent cross-layer violations.

Definition of done: ruff/mypy clean, routers only touch application interfaces, automated check for forbidden imports in domain.

### 2) CI/CD, Security, and Operations (ROADMAP_06)
Goal: safe, predictable delivery.
- Collapse CI to the canonical pipeline; remove duplicate workflows.
- Staging migrations blocking; prod/stage Cloud Run auth enforced (no unauthenticated deploys).
- Workload Identity everywhere; remove long-lived keys.
- Decide Neon preview DB posture (use or remove); document ownership of deploy jobs.
- Broker/worker readiness checks surface as 503 for mood-board enqueue.

Definition of done: single protected CI, auth-required deploys, no key JSON in CI, clear deploy ownership, queue health surfaced.

### 3) Platform Expansion & Generators (ROADMAP_07)
Goal: deterministic generation with safe APIs.
- Generator registry stable; add auth + payload limits to generator exports.
- W3C/DTCG tokens internal shape per 2025.10; flattened export remains public.
- React generator streams or fetches tokens (avoid embedding large JSON); CSS/W3C generator parity tests.
- Add schema validation for `component_meta`; document public vs internal export shapes.

Definition of done: generator endpoints guarded, tests for alias/composite exports, no large inlined JSON, docs aligned.

### 4) Performance, Cost, ML Inference (ROADMAP_08)
Goal: efficient and observable long-running jobs.
- Durable job execution for mood boards with broker/worker health paths; retries and backoff tuned.
- SSE endpoints non-blocking and observable (metrics/logs).
- Token export performance sanity (no oversized responses).
- Add basic cost/latency budgets to ops docs.

Definition of done: mood board jobs run asynchronously with readiness checks, SSE stable under load, export sizes bounded, budgets documented.

### 5) UX Resilience (Mood Board & Inspector)
Goal: trustworthy UX for long-running and read-only flows.
- Persisted mood boards with clear progress stages and retry affordances (UI-only).
- Token Inspector read-only, consuming `componentMeta`, integrated with Panels/Tabs; no runtime import of semantics scaffolding.
- CORS and error surfacing for mood-board flows with Celery offline paths.

Definition of done: UI shows stages/errors/retries, boards persist locally, inspector renders anatomy/bindings/accessibility intents.

### 6) Documentation & Governance
Goal: docs reflect merged code and enforce correct flows.
- Update architecture diagrams to new dependency flow; remove stale paths (e.g., `domain/models.py`, `services/*`).
- Document `Base.metadata.create_all()` as dev-only; Alembic required elsewhere.
- Keep DOCUMENTATION_INDEX and MASTER_ROADMAP in sync; add status badges (⏳/🚧/✅) to each roadmap.

Definition of done: diagrams updated, stale references removed, migration guidance explicit, indexes current.
